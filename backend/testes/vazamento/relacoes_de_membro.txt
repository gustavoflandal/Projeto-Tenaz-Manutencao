# Relações de membro de e para os papéis de execução (seção 2.2 de
# docs/2_ARQUITETURA_BANCO_DADOS.md). Um membro herda (INHERIT) ou assume (SET)
# os privilégios do papel: uma relação a mais é privilégio a mais, sem GRANT em
# tabela nenhuma (GRANT tenaz_dono TO tenaz_app faria do tenaz_app o dono de
# tudo).
#
# A suíte compara o catálogo com este arquivo nos dois sentidos. Fica de fora
# só a concessão pura de ADMIN (sem INHERIT nem SET), que o PostgreSQL 16+ dá a
# quem cria o papel sem ser superusuário, e que não transfere privilégio.
#
# Formato: membro  papel  OPCOES  # justificativa

tenaz_sinc_conexao          tenaz_sinc          INHERIT,SET  # usuário de conexão do sincronizador (seção 2.10)
tenaz_autenticacao_conexao  tenaz_autenticacao  INHERIT,SET  # usuário de conexão do pool das credenciais (ADR-011)
tenaz_manutencao            tenaz_dono          INHERIT,SET  # DDL de partição e manutenção física (seção 2.7); a leitura de credencial que ela traz é o achado ISO-E01-08
